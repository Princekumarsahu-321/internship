# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of this project.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately instead of creating a public GitHub issue.

### How to Report

Please use GitHub's **Private Vulnerability Reporting** feature available in
the Security tab of this repository.

If private vulnerability reporting is unavailable, you can contact the
repository maintainer privately through the contact information available
on the maintainer's GitHub profile.

### What to Include

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected file, endpoint, or component
- Potential impact
- Proof of concept, if available
- Any suggested mitigation or fix

### Response

We will review the report and acknowledge receipt as soon as reasonably
possible.

If the vulnerability is confirmed, appropriate steps will be taken to
address and release a fix.

Please do not publicly disclose the vulnerability until it has been
reviewed and addressed.

## Security Best Practices

Contributors should:

- Never commit passwords, API keys, tokens, or other secrets.
- Store sensitive configuration in environment variables.
- Keep dependencies updated.
- Review Dependabot and CodeQL security alerts.
- Do not include sensitive personal information in issues or pull requests.

## Scope

This security policy applies to the code and functionality contained in
this repository.

Thank you for helping keep this project secure.
